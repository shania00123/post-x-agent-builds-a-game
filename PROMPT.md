# The one prompt

This is the single prompt the game was built from. It is shown in the video
and it is the only brief the agent worked from:

> Build me a tiny browser game in ONE HTML file, no libraries: NEON DODGER.
> I steer a glowing ship with arrow keys or mouse/touch, dodge falling
> asteroids, collect stars for points, 3 lives, speed ramps up, game-over
> screen with score and press R to restart. Neon style, dark space
> background with a starfield.

## Creative decisions (decided in this session, before building)

- **Hook (first seconds):** "ONE PROMPT." in huge type, then the prompt itself
  on screen — the viewer instantly knows the premise: a prompt goes in,
  a game comes out.
- **Agent working:** an animated terminal — the agent's commands and the code
  appearing line by line. No fake footage: the commands shown are the ones
  actually run in this session (init, writing the game, running it).
- **The real result:** real gameplay, captured from a real browser session
  playing the actual game (Playwright driving the shipped `game/index.html`,
  autopilot on so the ship keeps flying and scoring). Nothing is a mockup.
- **End:** the game running full-screen with the call "Come build on
  make.fun", then make.fun's referral end card from the press pack
  (9:16 transparent webm, used as-is) with referral code `r27sfaxp` typed
  into its field.
- **Format:** vertical 1080x1920, ~40 seconds — built for the X phone feed.
